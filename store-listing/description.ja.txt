GitHub のコミットネットワークを、フォークも含めて
VSCode の Git Graph 風のビューアで一望できる Chrome 拡張機能です。

GitHub 標準のネットワークグラフは概観をつかむには良いのですが、
いざコミットの中身を読もうとすると別ページを何度も行き来する
必要があります。Git Graph for GitHub は、グラフとコミット詳細
パネルを 1 つのタブに並べて表示するので、リポジトリの履歴と
フォーク全体の関係を、タブを離れずに調べられます。

主な機能

・任意の公開 GitHub リポジトリのコミットグラフを専用タブで表示
・大きな履歴でも軽快に動く仮想スクロール
・フォーク対応:「本家のみ」(対象リポジトリのブランチのみ) と
 「フォーク含む」(ネットワーク全体) を切り替え可能
・コミット詳細パネル: 親 / 子コミットへの移動、ファイルごとの
 追加・削除行数とステータスを表示
・件名・SHA・作者・ブランチで読み込み済みコミットを検索
 (一致件数を表示、ワンクリックで古い履歴も読み込み)
・キーボード操作 (j / k、[ / ]、g / G、? でショートカット一覧)
・「このコミット表示へのリンクをコピー」で同じコミット・モードを
 再現するリンクを共有
・右クリックで SHA / コミットメッセージ / リンクのコピー、親
 コミットへのジャンプ
・ツールバーポップアップに「最近開いたリポジトリ」を保持 (個別削除・すべて
 削除に対応)。開いているリポジトリは既存のグラフタブを前面に表示
・グラフのヘッダーから、ポップアップに戻らずリポジトリを切り替え
・更新中も一覧・スクロール位置・選択を保持
・ブランチメニューにフォークのブランチも表示。詳細パネルで選択中の
 コミットを含むブランチを確認
・幅を変更・折りたたみできる詳細パネル
・システム設定に合わせる / ダーク / ライトのテーマ
・Chrome の言語設定に応じて英語 / 日本語 UI を自動切り替え

こんな人におすすめ

・フォークが多い OSS のメンテナ / コントリビューターで、
 誰がどこで分岐したかを素早く把握したい方
・VSCode の Git Graph 拡張機能の使い勝手をブラウザでも
 そのまま味わいたい方
・コントリビュート前にプロジェクトの構造をざっと把握したい方

プライバシー

・リモートコードの読み込みや、閲覧中ページへのコンテンツ
 スクリプト注入は一切なし
・個人データ・リポジトリ名・コミット SHA・URL・ページ内容を
 収集・送信することはありません
・GitHub への通信はブラウザから github.com および
 api.github.com への直接アクセスのみ
・改善のため、機能の利用状況やエラーの匿名統計を Aptabase
 (プライバシー重視の解析サービス) 経由で送信します。既定は
 ON で、オプションページからいつでもオフにできます。Cookie
 や永続的な識別子は使わず、個人やセッションを特定すること
 はできません。Aptabase キーを含まないビルドでは何も送信
 しません
・ローカルに保存するのは設定 (テーマ、デフォルトのグラフ
 モード) と「最近開いたリポジトリ」のリストのみ

権限について

・storage: 設定と最近のリポジトリ一覧をローカルに保存
・activeTab: ポップアップを開いたときに現在のタブの URL を
 読み取り、そのリポジトリをグラフ表示できるようにするため
・github.com / api.github.com へのアクセス: コミットネット
 ワークおよびコミットごとの詳細を必要なときに取得 (詳細は
 ブラウザでサインイン済みの GitHub セッションで取得し、取得
 できない場合のみ未認証の API を使うため、GitHub の 60 リク
 エスト/時の制限が適用されることがあります)
